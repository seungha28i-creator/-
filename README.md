# 🌿 온새미로 — 기후변화를 위한 전통수리 플랫폼

> **기후변화 해결을 위한 실천적 전통수리 플랫폼**  
> 나전칠기·옻칠·금계 등 한국 전통 수리 기법과 AI를 융합하여, 깨진 일상용품을 버리지 않고 아름답게 되살립니다.

<br>

## 📌 프로젝트 소개

매년 수천만 개의 생활용품이 수리 가능한 상태임에도 폐기됩니다.  
**온새미로**는 Claude API와 전통 공예 기법을 결합해 누구나 쉽게 수리에 도전하고,  
그 행동이 직접적인 기후 위기 대응이 될 수 있도록 설계된 플랫폼입니다.

<br>

## 🛠 기술 스택

| 구분 | 기술 |
|------|------|
| **Frontend** | React, Next.js |
| **Backend** | Node.js, Express |
| **AI** | Claude API (Anthropic) |
<br>

## ✨ 핵심 기능

### 1. 🔍 AI 파손 분석 & 수리 도안 가이드
- 사진 업로드 시 Claude API가 균열 형태·재질을 분석
- 최적의 전통 수리 기법(금계·옻칠·나전칠기) 추천
- 단계별 DIY 수리 가이드 자동 생성

### 2. 🌍 탄소 절감량 가시화 에코 대시보드
- 수리 1건당 절감 CO₂를 나무 심기 효과 등 직관적 지표로 환산
- 누적 환경 임팩트 실시간 시각화

### 3. 👨‍🎨 지역 장인 매칭
- 사용자 위치·기물 특성 기반 전국 전통 공예 장인 매칭
- 장인 프로필·경력·후기 조회 및 의뢰 신청

### 4. 📦 친환경 전통 재료 큐레이션
- AI 분석 결과 연동, 맞춤형 천연 재료 세트 자동 추천
- 천연 옻·자개·금분 등 친환경 인증 소재

### 5. 🏆 수리 챌린지 & 에코 포토카드
- 기법별 인증 미션 완료 시 포인트 적립 및 에코 캐릭터 성장
- SNS 공유용 탄소 절감 카드 생성으로 수리 문화 확산

## 🚀 시작하기

```bash
# 저장소 클론
git clone https://github.com/{seungha28i}/onsaemiro.git

# 프론트엔드
cd frontend
npm install
npm run dev

# 백엔드
cd backend
npm install
node index.js
```
